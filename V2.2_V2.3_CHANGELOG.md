# Enjiws Music V2.2 + V2.3 — Combined Update

This package is based on the supplied V2 app module and includes the V2.1 stability fixes already applied.

## V2.2 — Background playback
- Uses the dedicated Media3 `MediaSessionService` playback service.
- ExoPlayer owns audio focus handling.
- Playback pauses when headphones or Bluetooth audio output disconnects.
- MediaSessionService provides the system media notification and media-session controls while playback is active.
- Foreground media-playback service type and required permissions are declared in the manifest.

## V2.3 — Queue and playback flow
- Online Next/Previous controls in Now Playing now use the online queue resolver instead of calling `seekToNext()` on a one-item online Media3 playlist.
- Online Next supports shuffle and Repeat All; Repeat One continues to be handled by ExoPlayer.
- Automatic online queue advancement is guarded so multiple Next/autoplay operations cannot resolve streams concurrently.
- Failed stream resolutions are skipped; when Repeat is off and the online queue ends, the existing related-track radio fallback is retained.
- Previous restarts the current track when it has played for more than three seconds; otherwise it loads the previous online queue item.
- Upcoming online queue entries can be removed individually, in addition to clearing all upcoming entries.
- Queue metadata persistence remains enabled; expiring stream URLs are resolved again when a track is selected.

## Included V2.1 stability fixes
- Android 12L and older use `READ_EXTERNAL_STORAGE`; Android 13+ use `READ_MEDIA_AUDIO`.
- Stale lyric lookups are cancelled and cannot overwrite lyrics for a newly selected track.
- Lyrics HTTP requests have connection/read/call timeouts and close response bodies.
- LRC parsing supports multiple timestamp formats and multiple timestamps on one line.
- Duplicate unused playback-service source was removed.
