# Enjiws Music V2.1 — Stability Patch

## Changes
- Added legacy `READ_EXTERNAL_STORAGE` permission for Android 12L and below, while retaining `READ_MEDIA_AUDIO` for Android 13+.
- Prevented stale lyric requests from overwriting lyrics for a newly selected track; previous lyric jobs are cancelled and lyric state is cleared on track changes.
- Added connection/read/call timeouts to the shared lyrics HTTP client.
- Ensured HTTP responses are closed after reading.
- Expanded synced-LRC timestamp parsing to support `[mm:ss]`, `[mm:ss.xx]`, `[mm:ss:xxx]`, and multiple timestamps per line.
- Configured ExoPlayer audio attributes with audio-focus handling and pause-on-headset-disconnect behavior.
- Removed the unused duplicate `MusicPlaybackService`; the manifest and app already use `PlaybackService`.

## Validation
- AndroidManifest.xml parsed successfully.
- Source-level review completed.
- A Gradle build was not run because the supplied archive contains only the `app/` module and does not include the root Gradle wrapper/settings/build files.
